# SLG 玩法搜集与转换

SLG（含 CoK-like / 4X）玩法拆解、搜集与「用研格式」转换的工具集。

## 内容

- `slg玩法汇总/`：按社交 / 非社交（副玩法、模拟经营养成线）分类的玩法拆解表（xlsx）
- `用研格式示例/`：玩法验证、吸量点验证的用研填表格式（xlsx）
- `slg-gameplay-porting-agent.html`：纯浏览器端的玩法移植 Agent。API Key 仅保存在你本地浏览器（localStorage），不会上传任何服务器

## 使用

直接用浏览器打开 `slg-gameplay-porting-agent.html` 即可。填入你的 LLM / 搜索 API Key 后，按引导完成「玩法理解 → 移植方案 → 运营评估 → 文档生成」。

## 说明

本仓库只保留通用方法论与公开游戏的玩法分析，不含任何具体在研项目的世界观记忆或设计稿。
